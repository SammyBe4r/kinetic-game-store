# 🎮 KINETIC.GG — Loja de Jogos Digitais

Interface moderna e interativa de e-commerce para venda de chaves digitais de jogos (PC e Consoles), desenvolvida com **HTML5, CSS3 e JavaScript puro (Vanilla JS)** sem dependências externas.

🔗 **Demo ao vivo:** `https://sammybe4r.github.io/kinetic-game-store/` *(atualize após ativar o GitHub Pages)*

---

## ✨ Funcionalidades

- **Carrossel Hero em Destaque** com pausa automática ao passar o mouse e troca de banners.
- **Seletor de 4 Temas Dinâmicos** (*Roxo/Verde Neon*, *Preto/Dourado*, *Indigo* e *Crimson*) via CSS Custom Properties.
- **Busca e Filtros Combinados** por categoria, plataforma (Steam, Epic, PS5, Xbox, Switch), favoritos e ordenação (preço, desconto, avaliação).
- **Modal de Detalhes Completo** com seleção de edições (*Padrão* vs *Deluxe*) e requisitos de sistema.
- **Carrinho e Checkout Simulado** com cálculo de cupons (`KINETIC10`), pagamento via Pix/Cartão e **gerador automático de chaves (`XXXX-XXXX-XXXX-XXXX`)**.
- **Persistência de Dados** no navegador utilizando `localStorage` (carrinho, favoritos, chaves compradas e tema escolhido).
- **Atalhos de Teclado** (`/` para focar a busca e `Esc` para fechar modais).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3** (Grid Layout, Flexbox, Glassmorphism, Animações e Custom Properties)
- **JavaScript (ES6+)** (Gerenciamento de estado no cliente, DOM dinâmico e `localStorage`)
